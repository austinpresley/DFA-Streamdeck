## Download and install

Download `DFA-0.5.0.0.streamDeckPlugin` below. Double-click it, confirm in
Stream Deck, then drag a control from the DFA category onto a key.
The installer is 3.3 MB.

Requires macOS 13+ and Stream Deck 6.5+. Ordinary Stream Deck keys work;
Stream Deck + adds dials. Each placed control saves its own colors, label,
sound, volume and motion preferences. Value controls offer 1-point or 5-point
steps. [Full install guide](https://github.com/austinpresley/DFA-Streamdeck/blob/main/INSTALL.md).

## The useful information

DFA changes only its own display, bundled sounds and preferences. No mixer,
system volume, MIDI, OSC, keyboard shortcuts or other apps are affected.
There is no account, analytics or runtime internet connection. Apple's
first-launch security check is separate.
