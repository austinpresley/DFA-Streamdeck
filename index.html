A small, honest footnote.

v0.5.0 is a public preview. The signed universal build has passed software tests, native simulations and real-executable scenario replays. Physical installation, key and dial feel, listening, and device lifecycle checks remain pending. Built for Apple silicon and Intel; the Intel slice and oldest supported macOS have not been run.

DFA changes its own pixels, bundled sounds and preferences. Your mix, system volume and other apps stay yours. No account, analytics or runtime internet connection. Apple's first-launch security check is separate.

DFA's original code and assets are proprietary. Official binaries are free to install and use. License and third-party notices.
